# SCL AI Service

An AI-powered document intelligence system that extracts, processes, and understands PDFs using RAG (Retrieval Augmented Generation).

## Features
- PDF text extraction
- AI-ready text processing (coming soon)
- RAG-based question answering (coming soon)
- FastAPI backend

## Tech Stack
- Python
- FastAPI
- PyMuPDF
- ChromaDB (future)
- LangChain (future)

## How to Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
